# Расширения pi

Локальный пакет для pi (`@earendil-works/pi-coding-agent`). Упакован на версии 1.3.0.

- `walltime` — время с начала текущего сеанса в статусной строке, включая простой. При запуске, возобновлении, новом сеансе, fork и reload отсчёт начинается заново.
- `openai-weekly-limits` — остаток недельного лимита Codex, время до сброса и доступные резеты с ближайшей датой сгорания. Обновляется при старте, каждые пять минут и после завершения работы агента, если прошла хотя бы минута с последней попытки.

Оба индикатора работают в терминальном интерфейсе pi.

## Установка на другом компьютере

Сначала установите pi, чтобы команда `pi` была доступна, затем:

```sh
git clone https://github.com/kokamido/skills.git
cd skills
pi install ./pi-extensions
```

Перезапустите pi или выполните `/reload` в открытом сеансе. Для лимитов выполните `/login` и авторизуйтесь в провайдере `openai-codex` на этом компьютере.

`npm install`, сборка и копирование файлов в `~/.pi/agent/extensions` не нужны. Pi регистрирует пакет в личных настройках и загружает TypeScript прямо из клона: не удаляйте и не перемещайте этот каталог после установки.

Если эти расширения уже лежат в `~/.pi/agent/extensions` или `.pi/extensions`, перенесите старые копии **за пределы каталогов автозагрузки** перед подключением пакета, чтобы избежать двойных таймеров и запросов.

## Обновление и удаление

Из корня клонированного репозитория:

```sh
git pull
```

Затем `/reload` или перезапуск pi. Для отключения пакета:

```sh
pi remove ./pi-extensions
```

## Доступ и ограничения

Ключи, личные настройки и история сеансов в пакет не входят. Расширение лимитов получает OAuth-токен у pi и отправляет его только на `https://chatgpt.com/backend-api/wham/usage` и `https://chatgpt.com/backend-api/wham/rate-limit-reset-credits`. Запросы только читают данные: резеты не расходуются, токен расширением не сохраняется.

Эти внутренние endpoints ChatGPT могут измениться или оказаться недоступны для аккаунта; тогда индикатор покажет отсутствие данных. Совместимость со старыми версиями pi не проверена.
